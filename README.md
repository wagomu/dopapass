# ドパパス 🧠⚡

ドパミン駆動で ITパスポート試験を攻略する、スマホ向けのクイズ Web アプリ（PWA）です。

- **過去問モード**: IPA が公開している ITパスポート試験の問題（令和6〜8年度。図がないと解けない問題は除外）
- **オリジナルモード**: シラバスに沿って新しく作った問題 100問
- **ミックス／苦手つぶし**: 全部まぜて出す／間違えた問題だけを出す
- 1回10問・1問15秒。コンボ倍率、スピードボーナス、XP、レベルと称号、連続日数、効果音、ネットスラング解説つき

## iPhone で使う

1. Safari で公開 URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、全画面で動きます。一度開けばオフラインでも遊べます。

進捗（XP や苦手リスト）は端末のブラウザ内に保存されます。

## ローカルで動かす

```bash
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。localhost では Service Worker が無効です。オフライン動作を試すときは `?sw=1` を付けて開いてください。

## 問題データ

- `data/past.json`, `data/original.json`: アプリが読み込むデータ
- `data/parts/*.json`: 年度・分野ごとの元データ。編集したら次のコマンドで結合と検証をします。

  ```bash
  python tools/build_data.py
  ```

- データの仕様と解説の書き方は [tools/SPEC_questions.md](tools/SPEC_questions.md) を参照してください。
- 問題や JS/CSS を更新したら、`sw.js` の `VERSION` を上げてください。そうしないとキャッシュが更新されません。

## 出典・著作権

- 過去問は **独立行政法人情報処理推進機構（IPA）ITパスポート試験 公開問題** から引用しています。各問に「出典：令和◯年度 ITパスポート試験 公開問題 問◯」と表示します。
  - 表を文字に起こした問題など、一部を改変したものには「（改変あり）」と付けています。
  - IPA の案内では、過去問題の利用に許諾や使用料は不要とされています。ただし出典の明記が条件です。
- 解説文とオリジナル問題は、このアプリのために作成したものです。
- 本アプリは IPA とは関係ありません。
